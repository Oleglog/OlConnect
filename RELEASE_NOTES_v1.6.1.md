# OlConnect Client v1.6.1 — Исправление транспорта Mail.ru Docs и расширенная диагностика

Критическое обновление клиента для работы с транспортом Mail.ru Docs:

### Что нового:
1. **Устранена проблема недоставки пакетов в транспорте Mail.ru Docs**:
   - Формирование уникального `user.id` участника в редакторе OnlyOffice/R7, предотвращающее эхо-фильтрацию курсоров.
   - Поддержка экранированных кавычек во вложенных сообщениях курсора и кадров электронных таблиц (`saveChanges`/`excelAdditionalInfo`).
2. **Диагностика датапаса OpenFlux в реальном времени**:
   - В логах вкладки «Диагностика» отображаются счётчики пакетов и байтов (`OpenFlux datapath: tx=... rx=...`).
   - Логирование ошибок отправки пакетов через транспорт при их возникновении.
3. **Улучшена привязка физической сети VPN**:
   - Передача активной физической сети (`setUnderlyingNetworks`) при инициализации TUN-интерфейса OpenFlux.
