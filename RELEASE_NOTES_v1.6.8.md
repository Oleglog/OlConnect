# Release Notes - OlConnect v1.6.8

### Critical Fixes & Improvements
- **Resilient DNS-over-HTTPS (DoH) for Russia**:
  - Replaced blocked Cloudflare DoH (`1.1.1.1` / `cloudflare-dns.com`) with Yandex DoH (`https://common.dot.yandex.net/dns-query` and `77.88.8.8`) as primary with multi-endpoint fallback to Google DoH (`8.8.8.8`) and Cloudflare.
  - This completely fixes the issue where connections to Telemost and other transports showed "connected" on server/client but internet traffic did not pass and sessions were evicted as idle due to blocked DNS resolution.
- **Support for CUPS Online Room List & Format**:
  - Enhanced OpenFlux URI parser to recognize `?rooms=` and `?room=` query parameters generated by CUPS Online multi-channel exit nodes (`=== COPY THIS TO CLIENT ===`).
  - Added auto-inference of `CUPSONLINE` transport from `cups` / `cupsonline` URI hosts.
- **All Transports in Profile Editor**:
  - UI transport dropdown features: Auto, Yandex Documents (Volga), Yandex Documents (Classic), Mail.ru Documents, Yandex Telemost, CUPS Online, Bitrix24, and Avito.
