# OlConnect v1.6.0 — Крупный релиз клиента: Транспорт Mail.ru Docs, Яндекс.Документы и защита маршрутизации

Релиз **v1.6.0** объединяет все обновления мобильного клиента для Android: добавление транспорта через Mail.ru Docs, автоопределение типа документов, защиту от утечек трафика и поддержку сквозного шифрования.

---

### 🚀 Что нового

#### 1. Поддержка транспорта Mail.ru Docs
* **Обход блокировок через Mail.ru**: Добавлена поддержка туннелирования трафика через сервис совместного редактирования Mail.ru Docs (`doc.mail.ru`, `cloud.mail.ru`).
* **Бесшовная авторизация**: Встроена обработка токенов `r7/edit`, WebSocket соединений и прав доступа к документу.
* **Надежное подключение**: Реализована отказоустойчивая аутентификация (`effectiveUserID`), предотвращающая зависание на этапе авторизации в документе.

#### 2. Интеллектуальное автоопределение Яндекс.Документов
* Клиент автоматически определяет тип редактора (Volga `vyandex` или классический редактор `yandex`) при подключении по ссылке на документ.

#### 3. Безопасность и маршрутизация
* **Защита от утечек через `SO_BINDTODEVICE`**: Реализована строгая фильтрация пакетов на границе TUN-интерфейса (`tun0`). Приложения, не включенные в список маршрутизации, не могут отправлять данные в туннель в обход правил.
* **RFC 792 ICMP Port Unreachable**: Для не-DNS UDP-пакетов возвращается корректный ICMP-ответ, ускоряя переключение приложений на TCP-режим.
* **Сквозное шифрование AES-256-GCM**: Поддержка шифрования трафика поверх сессии документа. Ключ автоматически считывается из профиля, ссылки `olconnect://` или QR-кода.
* **Встроенный DNS-over-HTTPS (DoH)**: Быстрое и конфиденциальное разрешение доменных имен через Google, Cloudflare, Quad9 или Yandex без риска DNS-спуфинга.
